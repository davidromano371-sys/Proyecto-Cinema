# RUSH

## Descripción

RUSH es una plataforma web de streaming desarrollada como proyecto grupal académico. El sitio busca ofrecer una experiencia visual moderna, intuitiva y adaptable a distintos dispositivos y tamaños de pantalla, incluyendo computadores, tablets y dispositivos móviles, utilizando HTML, CSS y Bootstrap.



## Objetivo

Desarrollar una plataforma de streaming responsive que permita presentar películas y series mediante diferentes páginas y secciones, aplicando buenas prácticas de estructura, diseño y trabajo colaborativo con Git y GitHub.



## Tecnologías utilizadas

El proyecto RUSH está desarrollado utilizando las siguientes tecnologías:

- HTML5 para la estructura y organización del contenido.
- CSS3 para los estilos visuales y la personalización de la interfaz.
- Bootstrap 5 para el diseño responsive, componentes y adaptación a diferentes tamaños de pantalla.
- Git para el control de versiones.
- GitHub para el trabajo colaborativo, manejo de ramas y Pull Requests.



## Características principales

RUSH contempla las siguientes características principales:

- Diseño responsive adaptable a computadores, tablets y dispositivos móviles.
- Navegación mediante un Navbar responsive.
- Footer con información general y enlaces del proyecto.
- Secciones destinadas a películas y series.
- Páginas de detalle para el contenido disponible.
- Página Sobre Nosotros con información del equipo.
- Página de Contacto.
- Formularios de inicio de sesión y suscripción.
- Página personalizada de error 404.
- Organización del proyecto mediante componentes, estilos globales y estilos específicos por página.




## Estructura del proyecto

El proyecto se organiza en diferentes carpetas y archivos destinados a separar la estructura HTML, los estilos, los recursos visuales y las páginas internas.

De forma general, RUSH utiliza una organización similar a la siguiente:

```text
Proyecto-Cinema/
├── index.html
├── README.md
├── assets/
│   ├── img/
│   └── icons/
├── css/
└── paginas/
```



## Instalación y uso

Para ejecutar el proyecto de forma local:

1. Clonar el repositorio:

```bash
git clone https://github.com/davidromano371-sys/Proyecto-Cinema.git
```

2. Ingresar a la carpeta del proyecto:

```bash
cd Proyecto-Cinema
```

3. Abrir el archivo `index.html` en el navegador.

También puede utilizarse la extensión Live Server de Visual Studio Code para visualizar el proyecto durante el desarrollo.

## Fuentes utilizadas

Para mantener una identidad visual consistente en RUSH se utilizaron las siguientes tipografías:

- **Michroma** — utilizada en el logo de RUSH.  
  [Ver en Google Fonts](https://fonts.google.com/specimen/Michroma)

- **Montserrat** — utilizada principalmente en títulos y encabezados.  
  [Ver en Google Fonts](https://fonts.google.com/specimen/Montserrat)

- **Inter** — utilizada en textos, párrafos y contenido general.  
  [Ver en Google Fonts](https://fonts.google.com/specimen/Inter)

Las tipografías fueron seleccionadas para mantener una apariencia moderna, clara y coherente con la identidad visual del proyecto.
